Playwright Todo App Automation

Overview:
Web automation project for testing a Todo application using Playwright, JavaScript, and Node.js. Playwright Codegen was used to assist with initial test creation and locator identification, followed by manual review and refinement of the automation scripts.

Tech Stack:
Playwright
JavaScript
Node.js
VS Code
Git & GitHub

Test Scenarios:
Add a Todo item
Verify Todo item
Mark Todo as completed
Delete Todo item
Verify Todo item is removed
